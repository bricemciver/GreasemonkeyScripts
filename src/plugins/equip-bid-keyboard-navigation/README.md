# Equip-Bid Keyboard Nav

A userscript that uses Feedly-style navigation on Equip Bid auctions

## What it does

This script adds keyboard navigation to Equip Bid auction pages, allowing users to navigate through auction lots using keyboard shortcuts similar to Feedly. It enables scrolling through items, adding items to watchlist, opening items in new tabs, and viewing help documentation via keyboard commands.

## Features

- **Feedly-style Navigation**: Use 'j' and 'k' keys to navigate through auction lots
- **Watchlist Integration**: Press 'w' to add the current item to your watchlist
- **Tab Opening**: Press 'v' to open the current item in a new tab
- **Help System**: Press 'Shift+?' to view keyboard shortcuts help, 'Esc' to close
- **Auto Page Navigation**: Automatically loads next/previous pages when reaching the end of current page
- **Visual Feedback**: Selected lot is highlighted for easy tracking
- **Easy Installation**: Compatible with Tampermonkey, Greasemonkey, and other userscript managers

## Installation

1. Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/)
2. Download the userscript from <https://github.com/bricemciver/GreasemonkeyScripts/releases/latest/download/equip-bid-keyboard-navigation.user.js>

## How to Use

1. **Navigate to an Equip Bid auction page**: Go to any auction page on equip-bid.com
2. **Use keyboard shortcuts**:
   - Press **'j'** to scroll to the next auction item
   - Press **'k'** to scroll to the previous auction item
   - Press **'w'** to add the current item to your watchlist
   - Press **'v'** to open the current item in a new tab
   - Press **'Shift+?'** to view the keyboard shortcuts help dialog
   - Press **'Esc'** to close the help dialog
3. **Enhanced navigation**: When you reach the end of a page, the script will automatically load the next page
