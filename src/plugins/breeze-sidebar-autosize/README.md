# Breeze Sidebar Auto-size

A userscript that sizes the sidebar to fit the width of the content

## What it does

This script modifies the Breeze CHMS interface to automatically size the sidebar to fit its content width, rather than using a fixed width. This improves usability by preventing unnecessary horizontal scrolling and making better use of screen space when the sidebar content is narrow.

## Features

- **Content-based Sizing**: Automatically adjusts sidebar width to fit its content
- **Improved Usability**: Eliminates unnecessary whitespace and horizontal scrolling
- **Targeted Fix**: Specifically targets the Breeze CHMS sidebar element
- **Clean Implementation**: Uses pure CSS injection for minimal performance impact
- **Easy Installation**: Compatible with Tampermonkey, Greasemonkey, and other userscript managers

## Installation

1. Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/)
2. Download the userscript from <https://github.com/bricemciver/GreasemonkeyScripts/releases/latest/download/breeze-sidebar-autosize.user.js>

## How to Use

1. **Navigate to a Breeze CHMS page**: Go to any page in the Breeze CHMS system
2. **Observe the sidebar**: The sidebar will automatically adjust its width to fit the content
3. **Enjoy better layout**: No more wasted space or unnecessary scrolling when sidebar content is narrow
